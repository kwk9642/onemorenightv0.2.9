# One More Night — 開發鐵則

## 360°（以後所有開發）

角色、僵屍、戰鬥、移動、攻擊、推開、踩、持械、開門——**一律四向**。

- 貼圖最少 `down / right / up / left` 四套，缺一向不准接進遊戲。
- 移動是類比 360°（搖桿／WASD），貼圖對最近的前後左右。
- 禁止再做「只得正面」的動作片。推怪、揮武器、咬人，面向哪邊就往哪邊。
- 新動作先產齊四向再寫邏輯。不要先做一面再「之後補」。

v0.1 文字版不改這條（它沒有地圖走動）。v0.2 / R&D / 2.5D 全部跟這條。

## 範圍

- **v0.3 玩家版只做文字遊戲。** 主動戰鬥、像素走動、FightLab、MapWalk、FacingLab 不准掛上標題、不准接路由。`src/rd/` 檔留住，未叫不要接回玩家畫面。
- 先做人（走／潛／跑／赤手推／踩），四向齊才進下一招。
- **未叫開發僵屍就不要再生僵屍貼圖／AI／系統。** 戰鬥裡的怪只當活靶，沿用已有那套即可。
