## 0. 總評（先讀這段再填表）

方向是對的：人要更像自己、藥要像藥、裝備要有一條「找到藍圖 → 湊材料 → 在對的台子上做」的手感。問題不在題目，在**同時做九件事**會把 V0.2 的文字密度再加一倍，而玩家現在連前七晚都還在問。

建議的收法：

- **1（相片）**可以做，而且應該先做、做小。它不碰規則，只碰認同。
- **2（草藥＋病）**值得做，但是「肯塔基能採到的十幾種植物 × 八種病」，不是藥典。
- **3–9（工場線）**合成一條線，不要拆成七個獨立專案。現有「工坊」升級成「裝備工場」，底下再掛設備。稀有度沿用已有三檔，只加兩檔。藍圖只綁**可製造物**，搜到的菜刀不需要藍圖。
- **不要**為了傳奇套去重做戰鬥公式。套裝加成寫在文字戰已有的修正上（戰鬥、潛行、咬傷抗、負重、夜襲），不要另開一套傷害表。
- **分期**：0.3a 相片＋性別；0.3b 疾病八種＋草藥十六種＋識別／配製；0.3c 工場設備四台＋藍圖＋地區表；0.3d 稀有材料與傳奇兩套。不要一個 zip 全塞。

下面批評每條，再給可填的資料。數字是草案，實作時以程式常數為準，改數字先改這份再改表。

## 1. 上傳相片做主角（可設性別）——批評與最小範圍

可以做。不要做成角色創建的主菜。

**該做的**

- 相片只存在**這台裝置**。不上傳伺服器、不進存檔雲、不進 itch 頁。存檔 JSON 只存「有沒有自訂圖」的旗標與本機 blob 索引，或直接把縮圖進 localStorage。清資料就沒了，跟現在存檔一樣。
- 性別是**顯示與稱呼**（他／她／他們），以及少數衣服剪裁的文案。不要因此分戰鬥、不要分草藥吸收、不要分感染率。這遊戲的身體差別已經有特質點數，不要再疊一層隱藏修正。
- 沒上傳就用現有職業立繪。上傳失敗、檔太大、不是圖，就退回立繪，不要卡開局。
- 建議限制：一張、正方形裁切、檔案小於 2MB。開局選職業之後才出現「用我的臉／用立繪」。

**不該做的**

- 不要做人臉辨識、不要猜年齡、不要做「相機現場拍」。itch 頁是公開 HTML，本機選檔就夠。
- 不要讓委派、關係、情人線綁死性別二元。稱呼用玩家選的代詞即可。
- 不要因為有自訂臉，就把像素戰鬥或紙娃娃重做——V0.2 明文把那條關掉。

**結論**：1 是裝飾系統，工時短、風險在隱私說明要寫清楚。它不能當 2–9 的前置。可以進 0.3a，與草藥工場無關。

## 2. 草藥按現實世界來——批評

「按現實」是對的寫作態度，不是「把 NCBI 搬進遊戲」。現實草藥的問題是：同名植物部位不同、劑量差十倍、肝毒性、孕婦禁忌、和西藥相衝。文字遊戲若照抄，玩家會在資料庫裡淹死，醫生職業則強到沒有理由帶別人出門。

**收法**

- 只收**肯塔基／阿帕拉契／中西部路邊與林地真的長得出來的植物**（外加兩種藥房殘貨：阿斯匹靈、口服電解質，當對照，不當草藥）。
- 每種草藥只寫四件事：哪裡長、採到是什麼部位、主效、過用後果。不寫拉丁名長篇、不寫製劑學。
- 藥效分五類就夠：止血、清傷口、退熱止痛、腸胃、安神助眠。不要做抗癌、不要做催情、不要做「萬靈」。
- 草藥**不能清僵屍感染**。咬傷／抓傷那條仍走現有醫務室＋西藥＋時間。草藥最多把「傷口感染」的惡化變慢，給醫生一晚的窗口。否則農夫採一周就贏了。
- 識別綁 **醫療 medical** 與 **農耕 farm**。醫療高：喝下去之前就知道這是柳樹皮不是毒芹。農耕高：委派採藥時優先熟的種類、鮮品不易認錯。搜刮 scavenge 只影響「這棟屋後園能不能翻到乾貨」，不影響辨認。
- 醫生職業開局 medical 已高，給識別優勢，不給「一顆藥回滿」。農夫 farm 高，給產量與鮮品。兩人一起才是完整的草藥線。

**過用與藥性（一定要有，否則「按現實」是空話）**

每種草藥有 `dose`（安全次數／人／日）與 `toxic`（超過後的病）。例如聚合草內服傷肝，遊戲裡「內服」直接禁止、只准外敷；貫葉連翹讓情緒藥失效——這遊戲沒有 SSRI，就改成「安神類互相抵銷，連續吃三天情緒不回」。這樣藥性是規則，不是百科。

## 2b. 那代表有不同的病？——是，但只有八種

現有系統已經有：受傷、感染（僵屍）、情緒、飢渴。V0.3 病是**狀態**，不是新戰鬥。每個人最多同時兩種病（不含飢渴），避免狀態列爆炸。

建議八種，穩定 id 以後不要改：

| id | 中文 | 怎麼來 | 白天後果 | 惡化 | 西醫／醫務室 | 草藥對症 |
|---|---|---|---|---|---|---|
| `wound` | 開放傷口 | 戰鬥、夜襲、委派受傷 | 搜刮與戰鬥懲罰；噪音略增 | 不包紮 → `sepsis` | 繃帶＋藥品＋看護 | 西洋蓍、車前草外敷 |
| `sepsis` | 傷口惡化 | `wound` 拖過兩晚 | 高熱、不能出遠門 | 拖過三晚有機會死 | 藥品 2＋醫務室看護 | 紫錐花＋黃金印章只能**減速**，不能根治 |
| `bite` | 僵屍創 | 現有咬／抓 | 現有感染骰 | 現有 | 現有醫務室＋藥品 | **無效**（寫明，免得玩家囤紫錐花） |
| `fever` | 熱病 | 雨夜、疲勞疊加、腸胃惡化 | 行動格消耗＋1（一天變五格） | → 虛弱 | 退熱藥、休息 | 柳樹皮、接骨木漿果 |
| `dysentery` | 惡水 | 生水、腐食、髒手煮飯 | 水消耗加倍、情緒下降 | 脫水 | 電解質、煮沸、廚房 | 橡樹皮、薄荷；**不能只喝生水草藥茶** |
| `cough` | 肺熱 | 密閉樓、煙、冬春（若以後有季） | 潛行懲罰（咳嗽出聲） | 低機率 `fever` | 休息、乾淨床 | 毛蕊花、松針茶 |
| `insomnia` | 醒著 | 夜襲後、喪親、咖啡／纈草亂疊 | 休息職業效益減半 | 情緒底 | 休息、哨塔降低再襲 | 纈草、洋甘菊（互衝見下） |
| `poison` | 認錯藥 | 醫療低時生吃鮮品、或過用 | 一晚嘔吐、不能委派 | 低醫療再吃可能 `sepsis` 以外的猝死（極低，且只在「已知劇毒」兩種上） | 看護＋水 | 無；預防靠識別 |

設計意圖：醫生有事做，農夫有事採，廚子能用廚房擋住 `dysentery`。八種已經夠寫進資料庫一頁。不要再加寄生蟲線、不要加輻射、不要加「僵屍孢子過敏」。

**識別檢定（草案）**

鮮品進背包時是 `unknown_herb`。醫療 ≥ 4 或農耕 ≥ 5：當場點名。否則要在醫務室或菜園花 1 晚「認藥」（看護或耕作職業）。認錯機率：醫療 0–1 為 25%，2–3 為 10%，4+ 為 0%。認錯的後果走 `poison`。委派採藥時，隊員用自己的醫療／農耕做檢定——這就是「按技能優先搜自己熟的」在草藥上的落點。

## 2c. 十六種草藥（中西部／阿帕拉契，可進資料表）

欄位：`id`、中文名、英名、產地標籤、部位、主效、對症、安全劑量、過用、識別難度（1–5）、誰優先採到。

鮮品與乾品：鮮品效力 1.0、兩晚後變乾品 0.7，再三晚變廢。菜園可把已識別種子變成「畦」，耕作職業每晚產 1 鮮品，上限等於菜園等級。這讓農夫在中期不必天天出門採同一棵車前草。

### 常見（路邊、屋後、溪邊）——開局七晚就該見過

1. `plantain` 車前草 / Common plantain  
   產地：任何近郊、碎石路。部位：葉。主效：外敷清傷口、小止癢。對症：`wound`。劑量：外敷不限；內服無效。過用：無。識別 1。優先：農耕、搜刮。  
   文案用途：教玩家「不是所有藥都是喝的」。

2. `yarrow` 西洋蓍 / Yarrow  
   產地：田埂、向陽坡。部位：花葉。主效：外敷止血。對症：`wound` 當晚惡化骰 −1。劑量：外敷 2／日。過用：內服讓腸胃不適 → 低機率 `dysentery`。識別 2。優先：農耕、醫療。

3. `mint` 野薄荷 / Wild mint  
   產地：溪邊、濕地。部位：葉。主效：止嘔、熱茶安腸。對症：`dysentery` 輕症。劑量：茶 2／日。過用：胃灼熱、失眠略增。識別 1。優先：農耕、炊事。

4. `dandelion` 蒲公英 / Dandelion  
   產地：到處。部位：葉可食、根可烘。主效：當食物 0.5、輕利尿。對症：無直接病；缺糧時當菜。劑量：當菜不限。過用：夜裡起來小便 → `insomnia` 檢定略差。識別 1。優先：農耕。  
   批評：這味必須有，否則「按現實」卻沒有最常見的黃色頭。它不是藥王。

5. `willow` 柳樹皮 / Willow bark  
   產地：河岸。部位：內皮。主效：退熱止痛（水楊苷，阿斯匹靈的鄉下表親）。對症：`fever`、疼痛帶來的戰鬥懲罰減一檔。劑量：1／日。過用：胃出血風險——遊戲裡改為 `dysentery` 檢定，已有 `dysentery` 者禁止。識別 3。優先：醫療、農耕。  
   與藥房阿斯匹靈：阿斯匹靈是精製版，劑量穩、無識別檢定；柳樹皮便宜但佔識別與腸胃。

6. `pine_needle` 松針 / Pine needles  
   產地：林地。部位：綠針。主效：茶，抗壞血、清嗓。對症：`cough` 輕。劑量：茶 2／日。過用：無（但紫杉／紅豆杉針是另一種——見劇毒）。識別 2。優先：農耕、潛行戶外。

7. `cattail` 香蒲 / Cattail  
   產地：淺沼。部位：嫩芽、花粉。主效：**食物**不是藥。對症：無。識別 2。優先：農耕、搜刮。委派「覓食」應高機率帶回這個，而不是紫錐花。

### 少見（要走進林地、或委派「採藥」成功）

8. `echinacea` 紫錐花 / Purple coneflower  
   產地：草原殘塊、向陽。部位：根。主效：免疫支持，讓 `sepsis` 惡化延後一晚。對症：`sepsis` 減速、`fever` 略降。劑量：1／日、連用不超過三晚。過用：無效且浪費。識別 3。優先：醫療、農耕。  
   明文：對 `bite` 無效。

9. `elderberry` 接骨木漿果 / Elderberry  
   產地：林緣。部位：熟果（生果與葉有毒）。主效：熱病病程縮短。對症：`fever`。劑量：煮過的果 1／日。過用／生吃：`poison`。識別 4（生熟是關鍵）。優先：醫療。

10. `mullein` 毛蕊花 / Mullein  
    產地：乾荒、鐵道旁。部位：葉。主效：蒸氣或茶，對 `cough`。劑量：1／日。過用：葉毛刺激喉——先變糟再變好，寫進文案。識別 2。優先：農耕。

11. `chamomile` 洋甘菊 / Chamomile  
    產地：荒地、舊花園。部位：花。主效：安神、助眠。對症：`insomnia`。劑量：茶 1／晚。過用：與纈草同晚喝互相抵銷。識別 2。優先：醫療、炊事。

12. `valerian` 纈草 / Valerian  
    產地：濕地邊緣。部位：根。主效：強助眠。對症：`insomnia`（夜襲後第一晚特別有效）。劑量：1／晚。過用：隔天疲勞、戰鬥 −1 檔；連三晚失效。識別 3。優先：醫療。

13. `witch_hazel` 北美金縷梅 / Witch hazel  
    產地：林下。部位：枝葉蒸餾液（遊戲簡化：浸液）。主效：外敷收斂。對症：`wound` 輕、皮膚。劑量：外敷 2。過用：乾裂，無大害。識別 3。優先：醫療、搜刮（舊浴室櫃也有成品）。

14. `oak_bark` 橡樹皮 / Oak bark  
    產地：林地。部位：皮。主效：鞣質，止瀉。對症：`dysentery`。劑量：1／日。過用：便秘、胃口差（食物效益 −1）。識別 2。優先：農耕、建造（剝皮也像建材行為，建造技能可減識別失敗）。

15. `goldenseal` 黃金印章 / Goldenseal  
    產地：阿帕拉契林下，稀。部位：根。主效：強抗菌外敷／苦口。對症：`sepsis` 減速（比紫錐花強一檔），仍不清 `bite`。劑量：1／日、全局限持有 5（過採保護——這味現實裡被挖到近危）。過用：黏膜乾、`cough`。識別 5。優先：醫療。  
    地區：東側林地、諾克斯外圍、三月嶺附近權重高；芝加哥市區權重近 0。

16. `ginseng` 西洋參 / American ginseng  
    產地：阿帕拉契陰坡，極稀。部位：根。主效：當日疲勞下降、委派成功率微升。對症：無病；是「還能再走一趟」的根。劑量：1／三晚。過用：`insomnia`、心悸（情緒不穩）。識別 5。優先：農耕、潛行。  
    傳奇材料候選：見第 6 節 `mat_ginseng`。不要當回血藥。

### 劇毒對照（不進「藥櫃」，進「認錯表」）

- `yew` 紅豆杉針：長得像松針。認錯 `pine_needle` 且醫療 < 3 → `poison`，嚴重。  
- `pokeweed` 商陸漿果：長得有點像接骨木。生吃 → `poison`。  
這兩種**不賣效果**，只為了讓識別技能有牙齒。資料庫要寫「看起來像誰」。

### 配製（醫生／醫務室）

醫務室等級 1：能把鮮品做成「敷料」「茶」。  
醫務室等級 2：能做「煎劑」（柳樹皮、紫錐花根）。  
醫務室等級 3：能把黃金印章＋車前草做成「清創膏」（對 `wound`→`sepsis` 的轉換 −1 檔）。  

配製消耗 1 晚看護職業，產出 1–3 劑，視醫療技能。醫療 0–2 的人可以燒水泡茶，不能做膏。這就是醫生的中期位置：不是輸出，是把農夫採回來的葉子變成穩定劑型。

## 3. 可建造裝備工場（建築師）——批評

現有已有「工坊 workshop：派人打造才修裝備」。再單開一棟「裝備工場」而舊工坊只修牆，玩家會問兩個房間有什麼差別——V0.2 就是被這種問題逼出來的。

**收法**

- **不要第二棟房子。** 把工坊升到 2 之後改名顯示為「裝備工場」，或工坊 1＝修理、工坊 2＝解鎖設備槽、工坊 3＝同時開兩台設備。設施表仍是一個 `workshop` id。
- 「建築師」不要當第九職業先做。V0.2 八職業已經要教。建築師若要加，放 0.4，開局給建造 4、一張「工作台藍圖」、建材 8。0.3 用現有技工（建造 4）扛這條線。技工的身份從「修車的人」擴成「能把台子立起來的人」，文案改一句就好。
- 建造技能的用途要寫死，避免又變成「點了沒感覺」：  
  - 建設備的成功率與耗材折扣  
  - 製造時的稀有度上限（第 5 節）  
  - 設備損壞時的搶修  

若一定要職業叫建築師：特質「繪圖」開局多一張普通藍圖；缺點「紙上談兵」戰鬥 0 且不能警戒。仍然建議晚一版再加。

## 4. 工場要有設備才能做不同裝備——批評與四台上限

「各種設備」若做成十台，建材會把牆修垮，而且一天六格根本養不了這麼多升級。四台，每台兩級。

| id | 中文 | 解鎖製造 | 建材（級1／級2） | 額外 | 建造技能門檻 |
|---|---|---|---|---|---|
| `bench` | 鉗工台 | 近戰改裝、釘棒、撬棍加固、刀具開刃 | 8／14 | — | 建造 2／5 |
| `forge` | 鍛爐 | 金屬武器、板甲片、頭盔 | 12／20 | 燃油 2／4 | 建造 3／6 |
| `loom` | 縫製台 | 衣、背包、手套、帆布甲 | 6／12 | — | 建造 2／4 |
| `chem` | 製劑台 | 草藥膏、清潔酒精、土製繃帶（不是炸彈） | 6／12 | 藥品 1／2 | 醫療 3 或建造 4／醫療 5 |

工坊等級 1：只能修耐久，不能造新物。  
工坊等級 2：一個設備槽。  
工坊等級 3：兩個設備槽。  

同時開四台的方法：佔領更大的據點（五金行、倉庫）給「工場空間 +1」，不是無限升級同一間農舍。這與 V0.2「佔領不帶走舊升級」一致——搬走，台子留在舊地板上，藍圖還在腦子裡。

**值夜**

製造是晚上的職業，跟現有「打造 craft」合併。一晚一台一件。建造技能高可以「連作」：建造 ≥ 7 且設備級 2，一晚兩件普通，不能兩件稀有。六格白天不拿來造裝備——造裝備是回家之後的事，避免和出征搶同一條 AP。

設備會磨損。連用七晚未修：效率半。修理耗 1 建材＋打造職業。這給建造技能中期還有事做。

## 5. 裝備稀有度 × 建造技能——批評

V0.2 已經有 common／uncommon／rare。不要改名成一星到五星。玩家在資料庫認過這三個詞。只加兩檔：

| rarity | 中文 | 來源 | 建造技能門檻（製造時） | 搜刮權重修正 |
|---|---|---|---|---|
| `common` | 普通 | 到處、可造無藍圖的簡易物（釘棒、布條） | 0 | 1.00 |
| `uncommon` | 精良 | 多數店面、鉗工台級 1 | 3 | 0.45 |
| `rare` | 稀有 | 警局、醫院、倉庫深層；鍛爐或縫製台級 2 | 5 | 0.12 |
| `relic` | 遺物 | 指定地區固定表＋對應藍圖 | 7 | 0.03 |
| `legendary` | 傳奇 | 地區保底極低、或套件最後一件；不可「刷到整套」 | 9 且設備級 2 | 0.008 |

**製造時的稀有度不是骰子決定「這把刀突然傳奇」。**  
公式草案：

- 你只能製造「藍圖上寫死的稀有度」。釘棒藍圖就是精良，永遠不會造出傳奇釘棒。
- 建造技能 < 門檻：失敗耗一半材料，或成功但耐久只有 50%（二選一，建議後者，少懲罰挫敗）。
- 建造技能 ≥ 門檻 +3：耐久滿、額外一次「開刃」——面板 +1，仍不變稀有度。
- 傳奇只能造「已有藍圖的那一件」，不能用普通鐵造出傳奇。

搜刮技能影響的是**找到材料與藍圖**，不是找到之後用腦子把普通變成傳奇。兩種技能不要搶同一句「出貨」。

現有武器表（菜刀、獵刀、開山刀、撬棍、球棒……）全部對進這五檔即可，不必重做數字。開山刀已是 rare，維持。傳奇是新列，不覆蓋舊 id。

## 6. 高稀有度要同級材料 × 搜刮——批評

「稀有度相同的多種材料」這句話容易做成：傳奇要四種傳奇材料，於是沒有人做得到，或每個人都在同一張表上耕。

## 7. 所有裝備都要有藍圖才有——批評

這句必須改。

「所有裝備都要藍圖」會讓開局連釘棒都做不了，第一週更難，剛好是現在玩家在抱怨的點。也和現實衝突：把釘子敲進球棒不需要圖紙。

**改成三層**

1. **無藍圖可造**（普通，鉗工台或徒手＋打造）：釘棒、布包紮、木槍托、拆解廢鐵。清單列死，不超過 8 件。
2. **要藍圖才造**（精良以上所有新物，以及稀有改裝）。藍圖是物品，讀一次進「已知圖紙」，不佔格子。已知識別綁角色——人死了，活著的人若沒讀過，圖紙要重讀。鼓勵「讓建造高的人讀圖」。
3. **不可造、只可搜**：現成的手槍、警用防彈、商場名牌衣。可以拆成材料，不能無中生有。槍枝線若以後開放製造，另開「槍匠台」，本草案不包含土製火器（文字戰平衡與平台分級都不划算）。

藍圖從哪來：地區固定表、電台偶發、委派奇遇「一張地圖」改為有機會是圖紙、佔領據點時屋內書櫃。

藍圖稀有度＝成品稀有度。傳奇藍圖全局限一張可見（不是全局限一件成品——成品可以壞，圖還在）。

## 9. 傳奇最難出；一套齊有加成——批評與兩套就夠

傳奇若有六套，每套四件，等於 24 件終局裝備。文字戰的數字撐不住，資料庫也會變成遊戲本身。

**先做兩套，每套四件。第三套留空位。**

套裝規則：

- 2 件：小加成（一個技能 +1 或一項抗性）。
- 4 件：套裝敘事加成，寫進戰鬥或夜襲既有公式，不另開。
- 3 件沒有額外檔，避免強迫「差一件就焦慮」的中間態——要嘛 2，要嘛 4。
- 套裝件可與非套混穿。全身傳奇不是勝條件。
- 全局限：同一存檔世界，每件傳奇藍圖一張、每件成品最多兩件（壞了可再造一次）。防刷。

### 套 A `set_clinic`「值班未歸」

## 和 V0.2 規則的衝突清單（實作時逐條勾）

- 一天六格：製造在晚上，不吃白天格。配製也不吃白天格。
- 食物過十會腐：鮮草藥另計「藥櫃」格，不佔食糧堆，但鮮品仍會乾、會廢。不要讓藥櫃無限。
- 悄悄搜四成：特表同樣 ×0.4。傳奇不因悄悄而「更常出」（那是反直覺），只因更安全。
- 佔領不帶走升級：設備留在舊據點。藍圖在人身上。這是搬家的代價，寫進資料庫。
- 委派風險：採藥可帶 `wound` 或 `poison`（認錯）。不要只有甜奇遇。
- 僵屍感染線獨立：任何草藥文案出現「抗病毒」都不准進包。
- 開局難度：無藍圖的 8 件簡易物必須在沒有工場設備時也能做（至少釘棒與布包紮），否則新手攻略作廢。

## 資料庫要給玩家看的寫法（防 V0.2 再發一次「按鈕旁邊沒字」）

## 給程式的最小資料形狀（之後可直接拆 ts）

```text
Herb { id, nameZh, nameEn, biome[], part, effect, treats[], dosePerDay, overdose -> status, identify:1-5, freshDays, dryFactor }
Status { id, from[], dayEffect, worsenTo, westCure, herbCure[], blocksDispatch, blocksTravel }
Station { id, crafts: ItemId[], cost: {materials, extra}, skillReq }
Blueprint { id, itemId, rarity, station, mats: {id, rarity, n}[], skillReq }
RegionTable { locationId, entries: {kind: item|mat|herb|bp, id, w, stock}[] }
LegendSet { id, pieces[4], bonus2, bonus4, worldCap }
```

現有 `gear.rarity` 已是字串，向後加 `relic`／`legendary` 即可。存檔遷移：舊存檔沒有病、沒有藥櫃、沒有已知圖紙——當空陣列，不要判壞檔。
