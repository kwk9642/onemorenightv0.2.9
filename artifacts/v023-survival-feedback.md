# One More Night — 生存經濟修正（客戶反饋四條）

文件用途：實作底稿。不是給玩家的攻略。  
對應程式：[`src/game/engine.ts`](src/game/engine.ts) 的 `restNight`（喝水）、`canTravel` / `startMission`（燃油）、[`src/game/data.ts`](src/game/data.ts) 的 `LocationDef.fuel` 與 `neighbors`。  
建議版本：**v0.2.3**。不要塞進草藥 0.3b，也不要跟工場、藍圖、傳奇套同一包。這四條是現在讓人退坑的帳，不是新系統。

日期：2026-09-22

---

## 0. 總評

四條裡，兩條是規則說謊，兩條是缺設計。

| # | 玩家說的 | 判定 | 這包做什麼 |
|---|---|---|---|
| 2 水 | 三人、集水器三級，產 1.8、少喝 1.2，應該打平，結果每天還是少 | **公式和按鈕不一致**，不是玩家算錯 | 改成整數帳本。三級正好供三人。刪掉「約」 |
| 3 搬家後的油 | 佔領之後，去那邊的鄰近點不該耗油 | **合理，而且現在沒做**。油耗綁在目的地，不綁「離現在的家多遠」 | 現居地的鄰居油耗改 0 |
| 1 製油 | 油太少，要有辦法做油 | **缺一條慢產線**。只加掉落會把遠征變購物 | 晚上榨油，食物換油，每晚最多 1 |
| 4 四種模式 | 沙盒／休閒／正常／滅絕 | **要做，但沙盒不是中途作弊** | 開新局時選。舊存檔＝正常 |

水的修正和「鄰居不耗油」進**所有模式**。它們是地理和帳本，不是難度開關。難度只動掉落、夜襲、感染、起手、榨油的匯率。

草藥、八種病、工場四台、藍圖、傳奇套，維持上一份 [`v03-systems-draft.md`](v03-systems-draft.md) 的分期，不在這包。

## 1. 水：為什麼「應該打平」卻每天少

### 1.1 按鈕讓人這樣算

資料庫與房間說明寫的是：

- 每人每晚約喝 1
- 集水器產水約 `等級 × 0.6`
- 每級少喝約 `0.4`

三人、三級：

- 喝水 `3`
- 少喝 `3 × 0.4 = 1.2`（玩家把減免讀成全屋合計，這點和程式一致）
- 實喝 `3 − 1.2 = 1.8`
- 產水 `3 × 0.6 = 1.8`
- 淨值 `0`

這就是他們說的打平。帳本身沒算錯。

### 1.2 程式實際在跑的

[`engine.ts`](src/game/engine.ts) `restNight`：

```text
drinkers = 每人 1；highthirst 1.5；lowthirst 0.7
waste    = 第 16 天起 +1，否則 0
drink    = max(1, round(drinkers − 等級×0.4 + waste))
yield    = 等級>0 時 max(1, round(等級×0.6))，否則 0
```

資源是整數。`1.8` 和 `1.2` 從來沒有進過倉庫。

三人、普通口渴、三級，**第 16 天以前**：

- `round(3 − 1.2) = round(1.8) = 2` 喝
- `round(1.8) = 2` 產
- 淨值 0

所以「每天還是少」不是這一種人數在第 16 天前的常態。他們會少，是下面四種裡至少一種，而按鈕一個都沒寫：

| 實際情況 | 喝 | 產 | 淨 |
|---|---|---|---|
| 3 人，三級，第 16 天前 | 2 | 2 | 0 |
| 3 人，三級，第 16 天起（暗中 +1） | 3 | 2 | **−1** |
| 4 人，三級，任何天 | 3 | 2 | **−1** |
| 3 人，**二級**（`1.2` 產水被捨成 1） | 2 | 1 | **−1** |
| 3 人含 1 個 highthirst（1.5），三級 | `round(3.5−1.2)=2` | 2 | 0 |
| 5 人，三級 | 4 | 2 | **−2** |
| 另外：委派每人帶走 1 水 | 夜間公式之外 | — | 當天再 −1／人 |

減免 `等級×0.4` 是**全屋一共少喝這麼多**，不是每人少喝 0.4。三級只抵 1.2 人份，再被四捨五入。第四個人完全露在外面，產水卻不會因為人多而增加。

二級特別傷：玩家看到「產水約 1.2、少喝 0.8」，以為接近打平；程式是產 **1**、喝 **2**。

第 16 天的 `waste` 同時加在吃飯和喝水上，按鈕只講食物會腐，沒講水。

### 1.3 改法：整數帳，三級供三人

目標就用玩家的原話：**三人、集水器三級，當天打平。** 用他們能心算的整數，不再用 0.6／0.4。

```text
每人喝水 = 1
highthirst = 再 +1（這人算 2）
lowthirst  = 這人算 0（家裡有集水器 ≥1 時）；沒有集水器仍算 1
產水       = 集水器等級          // 1、2、3。等級 0 為 0
第16天額外喝水 = 僅當集水器等級為 0 時 +1
實喝 = 各人份額合計
淨值 = 產水 − 實喝
```

| 集水器 | 每晚產水 | 白給的人份 | 按鈕上要寫的那句 |
|---|---|---|---|
| 0 | 0 | 0 | 不產水。每人喝 1。第 16 天起再多喝 1 |
| 1 | 1 | 1 | 供 1 人。多的人各喝 1 |
| 2 | 2 | 2 | 供 2 人 |
| 3 | 3 | 3 | 供 3 人。三人整晚不欠水 |

驗算（普通口渴，第 16 天前）：

| 人數 | 等級 | 喝 | 產 | 淨 |
|---|---|---|---|---|
| 1 | 1 | 1 | 1 | 0 |
| 2 | 2 | 2 | 2 | 0 |
| 3 | 3 | 3 | 3 | **0** |
| 4 | 3 | 4 | 3 | −1 |
| 3 | 2 | 3 | 2 | −1 |
| 3 | 0 | 3 | 0 | −3 |

這比舊公式嚴在「二級不再靠四捨五入騙人」，鬆在「三級真的蓋住三人」。玩家要的就是後者。第四人開始欠水是對的：床可以加到 4、5、6，水不該跟著無限。

第 16 天的額外口渴**只在沒有集水器時出現**。有三級還每天 −1，等於懲罰已經升級的人，和「打平」對著幹。食物腐敗維持現況（超過 10 才腐），不要把水也腐掉。

highthirst 算 2，所以三人裡若有一個特別渴，三級變淨 −1。這是特質的代價，寫在特質說明，不寫進集水器。

lowthirst 在有集水器時不算人份。兩人普通 + 一人 lowthirst、三級：喝 2、產 3、淨 +1。合理。

### 1.4 日誌與按鈕（必做，否則改了還是怪）

每晚若水位有變，寫一行，用整數：

```text
喝了 {drink}，屋頂接了 {yield}。水 {before} → {after}
```

不夠喝仍走現有的口渴懲罰（`thirsty`）。產水在喝之後入帳，跟現在一樣：桶是空的，人還是會渴，屋頂的水要下一晚才喝得到。這點不用改，但那句話要留在集水器說明裡：「今晚接的水，明早才算數。」

刪掉所有「約 ×0.6」「少喝約 0.4」。中英日韓四處一起改：`why.ts` 的 `fac.water.effect`、`res.water.blurb`，`i18n.ts` 的 `bible.rule.night.body`。

委派帶走的水不進這條夜間公式。委派面板已經寫「帶走水 1」。若玩家把委派的水和過夜喝水加在一起，會以為集水器破了。日誌分開兩行即可，不必把委派算進喝水。

### 1.5 不要做的

- 不要把水改成小數庫存。文字遊戲的罐頭是整數。
- 不要讓集水器等級跟著人數自動變。人多是玩家的選擇。
- 不要在這包改食物公式。食物是另一條帳（廚房 −0.4、菜園要人耕、超過 10 才腐）。玩家這次沒有抱怨食物打不平。

## 2. 搬家之後，鄰居不耗油

### 2.1 現況

`LocationDef.fuel` 是**那個點自己的油價**，跟你住哪無關。

[`canTravel`](src/game/engine.ts) / `startMission`：只要 `resources.fuel < loc.fuel` 就走不了，出發時扣 `loc.fuel`。

例子：家在莫卓農舍。玫瑰鎮警局在 `neighbors` 裡，但警局 `fuel: 1`。人看得到、走得到，還是要燒 1 油。搬到警局之後，它的鄰居（農舍、倉庫、三月嶺、監獄……）同樣照各自的 `fuel` 扣，**不會因為你已經住在隔壁而變 0**。

遠城（蓋瑞、芝加哥）油價 3–4，這是對的。錯的是「隔壁也收過路費」。

### 2.2 規則

```text
fuelCost(home, dest) =
  0  若 dest 是 home，或任一方把另一方列在 neighbors
  否則 dest.fuel
```

用「雙向」：資料裡的 `neighbors` 大多是對稱的，但沒強制。只查 `home.neighbors` 會讓單向邊的人白付油。實作時兩邊都看。

佔領（`occupyHere`）已經把 `shelter.locationId` 改成新家，並把新家的 `neighbors` 標成已發現。油價函式讀現在的家即可，不用另存一張「已搬家」表。

後果：

- 住農舍：玫瑰鎮、倉庫、河畔雜貨、エコー、猛獁洞，油價 0。去路易維爾、辛辛那提，仍照表。
- 搬到玫瑰鎮警局：農舍、倉庫、三月嶺、監獄、勃蘭登堡、廢車場變 0。農舍那些**不再**是鄰居的點，恢復原價。搬家是換生活圈，不是永久免油護照。
- 點本身 `fuel: 0` 的，本來就是 0，不受影響。
- 芝加哥仍是終點油價。佔領芝加哥會直接勝利（`size === "metro"` 的現有判斷），不存在「住進芝加哥然後免費掃鄰州」。若以後有第二個 metro 不當勝利點，這條地理規則照用。

### 2.3 介面上要寫的

地圖上每個點，油價改顯示**從現在的家出發**的價格，不要顯示表定原價。

- 鄰居：`燃油 0 · 鄰近`
- 其餘：`燃油 {n}`

出發日誌：`去{loc}。鄰近，沒有燒油。` 或 `去{loc}，燒了燃油 {n}。`

資料庫加一句：油是離開生活圈的代價。搬了家，舊圈子要重新付油，新圈子的隔壁免費。

### 2.4 不要做的

- 不要「同一州全部免費」。電台二級已經能看見全圖，再免油等於遠征消失。
- 不要佔領後保留舊家的免費圈。兩個圈疊加，油就沒有意義。
- 不要在這包重畫鄰居名單。名單不對是資料問題，另開一張表再改。這包只改計價。

## 3. 製油：慢，每晚一桶，用多餘的食物

### 3.1 為什麼不只要調高掉落

現有油的來源：

- 起手：職業自帶 0–6，多數是 1–2
- 搜索：五金 `[0,2]`、倉庫 `[1,3]`、警局 `[2,5]`、諾克斯與大城市更高
- 遠門本身先收油，再讓你進去摸油

玩家的體感是「沒油就出不了遠門，遠門才有油」。鄰居改免費之後，肯塔基生活圈內的油壓會下降，這是對的。剩下的缺口是：**生活圈裡沒有辦法把日子變成油**。純加掉落會讓人蹲一個倉庫刷油，然後一次開去芝加哥。

### 3.2 設施：油桶 `still`

掛在現有設施表，不新開一棟房子。最大 2 級。建造花費沿用現有公式 `建材 × (現有等級+1)`。

| 等級 | 建材 | 匯率（每晚） | 條件 |
|---|---|---|---|
| 1 | 6 | 食物 3 → 燃油 1 | 當晚飯後食物仍 ≥ 3 |
| 2 | 12（再付 6×2） | 食物 2 → 燃油 1 | 同上，門檻改 ≥ 2 |

每晚最多 **1** 燃油。沒有人值夜就沒有油。沒有多餘食物就沒有油——不能把今晚要喝的湯榨了。

食物先結算吃飯、菜園、腐爛，**再**榨油。順序寫死：

1. 人吃飯、喝水  
2. 菜園與廚房入帳  
3. 食物超過 10 的腐爛  
4. 若有人職「榨油」且油桶 ≥1，且腐爛之後食物仍夠匯率，扣食物、燃油 +1  

這樣腐爛和榨油不搶同一堆：先爛掉多餘的，剩下的才進桶。玩家若想榨油，要讓庫存停在「夠吃、又夠匯率」，而不是屯到發臭。這和 V0.2「超過 10 會腐」是同一句話。

二級不是兩桶。二級只是匯率變好（3 食物變 2）。想一天兩桶，這包不給。

### 3.3 誰來做

新職業 id：`press`，中文「榨油」。

- 跟現有 `craft` 一樣，是晚上的工作，不吃白天六格。
- 油桶等級 0：按鈕禁用，提示「先造油桶」。
- 人在委派途中不能排這個職（現有 `assignJob` 已擋外出的人）。
- 技能：農耕或建造 ≥4 時不改產量（仍是 1），只讓日誌寫「{name} 知道哪一桶還能燒」。不要用技能把 1 變成 2。技能的報酬留到工場那包。
- 技工（建造 4）和農夫（農耕 4）都能值。醫生不能靠醫療榨油。

不另做「塑膠廢料 → 油」。材料已經要拿去補牆和升級。兩種原料會讓人不知道該燒哪一種。這包只有食物。

### 3.4 和遠征的關係

芝加哥、蓋瑞的油價維持原表（這包neighbors規則之後，它們仍不是肯塔基農舍的鄰居）。

正常模式要湊一次遠門：油桶二級、每晚 1 油、連續幾晚不把食物榨穿。這是「有辦法」，不是「有油用」。

休閒與滅絕只改匯率和上限，不改「鄰居免費」。見第 4 節。

### 3.5 文案（按鈕旁三行）

1. 把多餘的食物做成一桶油。  
2. 要油桶。一級 3 食物，二級 2 食物。當晚飯和腐爛之後才扣。每晚一桶。  
3. 沒人值榨油，桶是空的。食物不夠匯率，這晚不做。

日誌：`{name} 用食物 {n} 榨了 1 燃油。`  
失敗也要寫：`食物不夠榨油。` 不要靜默。

### 3.6 存檔

`FacilityId` 加 `"still"`。`JobId` 加 `"press"`。  
舊存檔沒有這兩個欄位：設施補 0，職業若讀到未知值就當 `rest`。不要把舊檔判壞。

四語 key：`fac.still`、`job.press`、`log.press`、`log.press.short`。

## 4. 四種模式

### 4.1 原則

- 只在**新遊戲**選。存檔上記 `mode`。舊檔、沒有欄位的檔，都是 `normal`。
- 中途不能改模式。否則「滅絕通關」沒有意義，沙盒會變成暫停改資源。
- 勝敗條件四種相同：清芝加哥並佔領為勝，全滅為敗。沙盒可以關掉勝利結算（見下），預設仍開著。
- 水的整數帳、鄰居油價 0、油桶的存在，四種都有。模式只改數字。

標題四張卡，各一句人話，不要四段說明書。

### 4.2 `casual` 休閒

仍然是這一局：六格、永久死亡、地點會搜光、地圖不說謊。只是容錯大。

| 項 | 值 |
|---|---|
| 搜索掉落 | ×1.5，進位，每種至少比正常多 0（抽到 0 仍是 0） |
| 悄悄搜索 | 特表與安靜搜的收益 ×0.55（正常是 ×0.4） |
| 起手資源 | 職業表 ×1，另送食物 +4、水 +4、燃油 +2 |
| 夜襲機率 | ×0.6，上限仍 0.45 |
| 近戰失敗感染 | 0.20（正常近戰約 0.35／0.18，這包把休閒的近戰失敗固定 0.20，開槍維持偏低） |
| 食物開始腐 | 超過 14（正常 10） |
| 第 16 天額外消耗 | 關 |
| 榨油 | 匯率 −1（一級 2 食物、二級 1 食物），仍每晚 1 桶 |
| 遠程油價 | `max(0, 表定 − 1)`。鄰居仍是 0，不要減成負數 |

容易通關指的是死少、油夠、飯夠，不是芝加哥沒有僵屍。僵屍數量不乘。

### 4.3 `normal` 正常

就是 v0.2.3 的底。現在的難度，加上這份的水、鄰居油、油桶。

不要在「正常」裡偷偷放休閒的送資源。玩家選正常，是要現在這局，不是要我們覺得公平的那局。

### 4.4 `extinct` 滅絕

比現在難，但仍是同一張圖、同一個勝利。不要加新怪、不要改六格。

| 項 | 值 |
|---|---|
| 搜索掉落 | ×0.7，無條件進位到至少 0；抽到區間下限時允許 0 |
| 悄悄搜索 | ×0.25 |
| 起手 | 職業表每項 −1，最低 0。食物與水最低各留 1 |
| 夜襲 | 公式不變，上限 0.60（正常 0.45） |
| 近戰失敗感染 | 0.50 |
| 食物開始腐 | 超過 8 |
| 額外消耗 | 第 8 天起，沒有集水器則喝水 +1；吃飯的 waste 也改成第 8 天 +1 |
| 榨油 | 一級 4 食物、二級 3 食物，每晚最多 1，且隔夜才能再榨（做完的那晚設 `stillCooldown = 1`） |
| 遠程油價 | 表定 +1。鄰居仍是 0 |
| 電台叫人 | 0.12 改為 0.06。叫到地點的 0.35 不變 |

滅絕裡鄰居免費仍然保留。那是搬家的地理，不是慈悲。懲罰在遠門更貴、產油更慢。

### 4.5 `sandbox` 沙盒

開局第二頁，不要跟三個模式搶同一層資訊。

玩家可調，全部只影響這局的起點與係數：

| 項 | 範圍 | 預設（等於正常） |
|---|---|---|
| 額外同伴 | 0–5 | 0 |
| 同伴職業 | 從八職業裡選，可重複 | — |
| 食物／水／建材／藥／彈／油 | 各 0–40 | 用職業起手，不額外加 |

額外同伴在開局塞進房子，直到床位。床不夠的人**不生成**，並在確認頁寫「床只有 {n}，多的人不會出現」。沙盒也不准無限住。要更多人，自己先加寢室——或把「忽略床位」做成一個預設關閉的勾。預設關。勾了之後容量當 8，夜襲與喝水照人數算，免得沙盒連水帳都不成立。

沙盒不提供「中途加資源」按鈕。那是除錯，不是模式。

沙盒的通關若有人拿去貼，標題結算要寫「沙盒」。不要和正常、滅絕混在同一句「你撐到了芝加哥」。

休閒與滅絕的卡片上不要再塞滑桿。兩個極端用第 4.2、4.4 的表就好。滑桿是沙盒專用。

### 4.6 介面

新遊戲流程：

1. 四張卡：休閒、正常、滅絕、沙盒。  
2. 沙盒才進入滑桿頁，其餘直接進選職業。  
3. 職業、特質、出生點維持現況。  
4. 標題「繼續」不顯示模式選擇。存檔已經定了。

卡上的一句：

- 休閒：規則相同，飯和油寬一點，仍會死人。  
- 正常：現在這一版。  
- 滅絕：同樣的路，更少的東西，更貴的遠門。  
- 沙盒：自己定同伴、倉庫和難度。通關會註明沙盒。

結算與開發日誌不需要四段更新文。v0.2.3 的日誌用一節寫完：水改整數、鄰居不耗油、可以榨油、開局四種模式。
