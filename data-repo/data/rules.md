# 公式

| id | name | formula | note |
| --- | --- | --- | --- |
| fight-power | 文字戰鬥火力 | power = (戰鬥技能×8 + 武器攻擊×2) × 狀態修正 | 近戰／開槍／側翼再加權。槍：+18+耗彈×6，耗彈=min(庫存, 2+僵屍/8)。側翼：+潛行×4。 |
| fight-score | 勝負 | score = power×(0.8~1.2) − (該地僵屍×7 + 噪音)×(0.8~1.2) | score>25 多殺2；>0 多殺1。槍保底殺 2+耗彈/2。失敗近戰感染 35%/18%，開槍較低。 |
| sim-hit | 2.5D 揮擊（研發，未進 v0.1） | 傷害 = 10 + 戰鬥技能 + 武器攻擊 | 只在出征模擬畫布。v0.1 出征仍走上面文字戰鬥。 |
| raid | 夜襲 | 機率 = clamp((100−圍牆)/220 − 警戒人數×0.08 − 哨塔等級×0.06, 0, 0.45) | 中了：隨機在家的人傷 10–28、感染 20%、食物−2、圍牆−8。修繕過夜約+8牆，打造耗1建材約+6牆。 |
| upgrade | 建造花費 | 建材 = 基價×(現有等級+1)；額外資源同樣乘級 | 醫務室額外要藥；無線電額外要燃油。按鈕會列出全部，不夠寫「缺xx」。 |
| weapon-cond | 武器耐久 | 實際攻擊 = round(面板攻擊 × 耐久係數) | 耐久 0 當徒手（攻擊 0）。槍沒子彈在文字戰不能選開槍。 |
